SenseHat_efb 1.0.0

BSP package for the Raspberry Pi Sense HAT (v2) on a Lattice MachXO4 device. It consists of an APB pass-through block that gives the MachXO4 EFB secondary I2C controller (I2C2) its own address window, and a C driver set that runs on the RISC-V SM (or any CPU on the same APB bus). The drivers cover the I2C master, the 8x8 RGB LED matrix and 5-way joystick (ATTINY88-MUR) and the five sensor devices of the HAT.

1. Dependency on the lscc_efb IP

SenseHat_efb does not contain an I2C controller. It only forwards its APB slave port to the lscc_efb IP (Lattice EFB Module, version 1.3.0, IP vendor latticesemi.com, library module) and relies entirely on that block's hardened secondary I2C controller. A design that uses SenseHat_efb must therefore contain one lscc_efb instance, connected as described below. The driver cannot work without it.

APB interconnect --APB_S0--> SenseHat_efb --APB_M0--> lscc_efb (APB_S0)
                                                         |  i2c2_scl / i2c2_sda --> Sense HAT SCL / SDA

Every APB signal is passed through 1:1: no registers, no clock, no reset, no parameters.

Other HAT signals (not part of this IP, connect them as GPIO): INT1 = Raspberry Pi GPIO23 (joystick change, active high), INT2 = GPIO24 (IMU interrupt), PROG_RST_N = GPIO25 (active-low reset of the ATTINY88).

  • LED matrix: one write of 193 bytes. Byte 0 is the start register 0x00; bytes 1 to 192 are 8 rows x 24 bytes (8 red, 8 green, 8 blue per row). Keep colour values at 0 to 31 for a safe result; the driver clamps to SENSEHAT_COLOR_MAX (0x3F).
  • Joystick: register 0xF2, 1 byte: Down 0x01, Right 0x02, Up 0x04, Center 0x08, Left 0x10 (1 = pressed).

4. Driver functions

All calls are blocking, use a bounded poll loop and return SENSEHAT_OK (0) or a negative error code. Sensor drivers need no extra hardware beyond the I2C bus. Files: SenseHat_efb.c/.h and SenseHat_efb_regs.h, lps25h.c/.h, hts221.c/.h, lsm9ds1.c/.h, tcs3400.c/.h, tcs34725.c/.h.

4.5 tcs3400: RGB colour sensor on the Sense HAT v2 (0x39)

The Sense HAT v2 carries a TCS3400-family sensor (ID register 0x92 reads 0x90). Registers are addressed directly (ENABLE 0x80, ATIME 0x81, CONTROL 0x8F, ID 0x92, STATUS 0x93, data 0x94 to 0x9B); there is no command byte. The data bytes are read as low/high pairs starting on an even address. Source: TCS3400 datasheet DS000411.

FunctionDescription
tcs3400_init(inst, atime, gain)Checks ID[7:2] = 100100, sets integration time (cycles = 256 - ATIME, 2.78 ms each; TCS3400_ATIME_103MS = 0xDB) and gain (TCS3400_GAIN_1X/4X/16X/64X), writes the reserved CONFIG bit (0x40), powers up and starts the conversion.
tcs3400_id()ID byte read by the last init.
tcs3400_read(inst, &data)Raw clear/red/green/blue, colour r8/g8/b8 normalised to clear (0 to 255) and a saturated flag (reduce gain or integration time when set).
tcs3400_power_down(inst)Power down.

Errors: TCS3400_ERR_ID (-50), TCS3400_ERR_NOT_READY (-51, no completed RGBC cycle yet). Illuminance is not computed: the datasheet gives no lux formula.

4.6 tcs34725: RGB colour sensor of the TCS3472x family (0x39 or 0x29)

FunctionDescription

5. Usage example

#define APB_HZ 12000000u
static struct sensehat_efb_instance hat;
static struct hts221_instance hts;
static uint8_t fb[SENSEHAT_FB_BYTES];

sensehat_efb_init(&hat, 0x8800u);                 /* base address of SenseHat_efb */
sensehat_i2c_init(&hat, APB_HZ, 100000u);         /* EFB clock and bus rate */

sensehat_fb_clear(fb);
sensehat_fb_set_pixel(fb, 3, 4, 31, 0, 0);        /* red dot */
sensehat_fb_write(&hat, fb);

lps25h_init(&hat);  hts221_init(&hat, &hts);
lsm9ds1_ag_init(&hat);  lsm9ds1_mag_init(&hat);
tcs3400_init(&hat, TCS3400_ATIME_103MS, TCS3400_GAIN_16X);

struct lps25h_data p;
if (lps25h_read(&hat, &p) == SENSEHAT_OK) { /* p.pressure_x100, p.temp_x100 */ }

Optional hooks: set hat.delay_us to a microsecond delay function (used by tcs34725_init and as a real-time wait). The sensor drivers use integer maths only; on a CPU without hardware multiply and divide the compiler library supplies them.
