TTS_APB macro/IP

Description

TTS_APB is an English text-to-speech peripheral with an APB slave interface. The processor writes ASCII text into the block, one character per register write. The block stores the text in two line buffers of 128 characters each: one line can be spoken while the next one is received. A built-in speech processor (TTSCPU) converts the text into phonemes and prosody with letter-to-sound rules, and a formant synthesizer produces 16 kHz audio samples. Two clocks: PCLK for the APB interface (any frequency) and TTS_CLK for the synthesizer (24 MHz). A 10-bit PWM output (32 kHz carrier at the 24 MHz TTS_CLK) drives a speaker through a simple amplifier. The only external pin is the PWM output.

A line ends at a carriage return or line feed, or after 128 characters. Plain text is spoken; these characters control the timing:

  • space: word gap, 75 ms (also a gap between two tones)
  • "-": half gap, 45 ms
  • ",": short pause, 125 ms
  • ". ; :": sentence pause, 170 ms
  • "?": rising intonation, then 170 ms; "!": emphasis on the last word, then 170 ms
  • "#Hz,ms#": a sine tone, for example #1318,125# (up to 7.9 kHz and 20 s; a line with an open command is ignored)

Registers

OffsetNameContent
0x00IDRead only: 0x54545302
0x04CTRLWrite: bit 0 START (speak the completed line), bit 1 CLEAR (discard queued text, ignored while busy)
0x08STATUSBit 0 BUSY, bit 1 READY (a complete line is waiting), bit 2 DONE (sticky), bit 3 PLAY, bit 4 DROP (sticky), bits 15..8 LEN (length of the oldest complete line, 1..128)
0x0CDATAWrite: one text character; read: last character written

Driver functions (driver/tts.h)

  • unsigned char tts_init(struct tts_instance *this_tts, uint32_t base_addr)
    Binds the instance to the base address of the block and checks the ID register. Returns 0 on success, 1 on a null pointer, 2 if the ID register does not match.
  • uint32_t read_tts_status(struct tts_instance *this_tts)
    Reads the STATUS register. The result is a combination of the TTS_STATUS_* bits (BUSY, READY, DONE, PLAY, DROP).
  • void write_tts_control(struct tts_instance *this_tts, uint32_t value)
    Writes the CTRL register with a combination of the TTS_CTRL_* bits (START, CLEAR).
  • uint32_t write_tts_phrase(struct tts_instance *this_tts, const char *buf, uint32_t length)
    Writes length characters of buf into the block, one DATA write per character. The buffer carries its own line terminator (CR or LF). Returns the number of characters written.

tts_regs.h holds the register offsets, the bit definitions and TTS_LINE_MAX (128).

Example: initialise the block and speak one sentence

#include "tts.h"

static struct tts_instance tts0;

void speak_hello(uint32_t tts_base)          /* base address of the TTS_APB instance */
{
    static const char msg[] = "Hello, Lattice is talking!\r";   /* CR ends the line */

    if (tts_init(&tts0, tts_base) != 0u) {
        return;                              /* block not found at this address */
    }

    while (read_tts_status(&tts0) & TTS_STATUS_BUSY) {
    }                                        /* wait until the previous speech is done */

    write_tts_phrase(&tts0, msg, sizeof(msg) - 1u);

    while (!(read_tts_status(&tts0) & TTS_STATUS_READY)) {
    }                                        /* the line is complete and waiting */

    write_tts_control(&tts0, TTS_CTRL_START);   /* start speaking */

    while (read_tts_status(&tts0) & TTS_STATUS_BUSY) {
    }                                        /* speech and fade-out finished */
}
