FXLS8971_I2C macro/IP

Description

FXLS8971_I2C connects an NXP FXLS8971CF 3-axis accelerometer to a RISC-V SoC. The IP is an APB peripheral with a single-master I2C controller in the FPGA fabric (soft logic), so the accelerometer can sit on any pair of user I/O pins, not only on the hardened EFB I2C pins. The package includes a two-layer BSP driver: an I2C layer (i2c_master.h) and an FXLS8971CF device layer (fxls8971.h) that configures the sensor and reads acceleration and temperature.

  • APB slave, 32-bit registers, PREADY always high (zero wait states).
  • One clock (PCLK). SCL frequency: f_SCL = f_PCLK / (4 * (PRESCALE + 1)); 100 kHz, 400 kHz and up to 1 MHz (Fast-mode Plus).
  • Byte-level command engine: optional START or repeated START, one byte WRITE or READ (ACK or NACK), optional STOP.
  • SCL clock stretching by the target is supported.
  • Open-drain pins I2C_SCL and I2C_SDA, with a 2-flip-flop input synchroniser. Pull-up resistors are needed on the board.
  • Parameter PRESCALE_RESET: PRESCALE value after reset (default 43, about 100 kHz at 17.73 MHz).

The other FXLS8971CF pins (SA0, SPI_CS_B/WAKE_UP, INT1, INT2, BT_MODE) are not part of this IP; connect them to a GPIO block if the firmware has to drive or read them. In I2C mode (INTF_SEL = GND) SA0 selects the address (0 = 0x18, 1 = 0x19) and SPI_CS_B should be kept high.

Driver library

The driver/ folder is copied into the BSP of every SoC that uses this IP. All transfer functions are blocking and poll STATUS.BUSY with a timeout, so a stuck bus never hangs the CPU.

I2C layer (driver/i2c_master.h, i2c_master_regs.h)

Return codes: I2C_MASTER_OK (0), I2C_MASTER_ERR_PARAM (1), I2C_MASTER_ERR_ID (2), I2C_MASTER_ERR_NACK (3), I2C_MASTER_ERR_TIMEOUT (4).

  • uint8_t i2c_master_init(struct i2c_master_instance *this_i2c, uint32_t base_addr)
    Binds the instance to the base address of the block and checks the ID register. Releases the bus if it is still owned.
  • uint32_t i2c_master_set_speed(struct i2c_master_instance *this_i2c, uint32_t sys_clk_hz, uint32_t scl_hz)
    Sets PRESCALE from the APB clock frequency; the bus is never faster than asked. Returns the real SCL frequency in Hz (0 on error).
  • uint32_t i2c_master_status(struct i2c_master_instance *this_i2c)
    Reads the STATUS register (I2C_MASTER_STATUS_* bits).
  • uint8_t i2c_master_write(struct i2c_master_instance *this_i2c, uint8_t addr7, const uint8_t *data, uint32_t len, uint8_t stop)
    START, address + W, len data bytes, then STOP when stop is not 0. Without STOP the next call makes a repeated START.
  • uint8_t i2c_master_read(struct i2c_master_instance *this_i2c, uint8_t addr7, uint8_t *data, uint32_t len)
    START, address + R, len data bytes (NACK on the last one), STOP.
  • uint8_t i2c_master_write_reg(struct i2c_master_instance *this_i2c, uint8_t addr7, uint8_t reg, const uint8_t *data, uint32_t len)
    Register write: START, address + W, reg, data, STOP.
  • uint8_t i2c_master_read_reg(struct i2c_master_instance *this_i2c, uint8_t addr7, uint8_t reg, uint8_t *data, uint32_t len)
    Register read: START, address + W, reg, repeated START, address + R, data, STOP.
  • uint8_t i2c_master_probe(struct i2c_master_instance *this_i2c, uint8_t addr7)
    Returns I2C_MASTER_OK when a target acknowledges addr7.

FXLS8971CF layer (driver/fxls8971.h)

Return codes: FXLS8971_OK (0), the I2C_MASTER_ERR_* codes, FXLS8971_ERR_ID (10, WHO_AM_I is not 0x83), FXLS8971_ERR_TIMEOUT (11, mode change did not happen). Ranges: FXLS8971_RANGE_2G / 4G / 8G / 16G. Data rates (low-power mode): FXLS8971_ODR_3200HZ down to FXLS8971_ODR_0HZ781.

  • int fxls8971_init(struct fxls8971_instance *dev, struct i2c_master_instance *i2c, uint8_t addr, enum fxls8971_range range, enum fxls8971_odr odr)
    Checks WHO_AM_I, puts the sensor in Standby, selects low-power mode, the range and the data rate, and makes it Active.
  • int fxls8971_read_reg(struct fxls8971_instance *dev, uint8_t reg, uint8_t *val) and int fxls8971_write_reg(struct fxls8971_instance *dev, uint8_t reg, uint8_t val)
    Single register access.
  • int fxls8971_set_active(struct fxls8971_instance *dev, uint8_t active)
    Standby (0) or Active (1); waits until SYS_MODE follows. Configuration registers can only be written in Standby.
  • int fxls8971_data_ready(struct fxls8971_instance *dev)
    Returns 1 when a new X/Y/Z sample is ready (INT_STATUS.SRC_DRDY), 0 when not, a negative value on an I2C error.
  • int fxls8971_read_xyz(struct fxls8971_instance *dev, struct fxls8971_data *data)
    Reads X, Y and Z in one burst (registers 0x04..0x09) as signed 12-bit samples. Clears SRC_DRDY.
  • int fxls8971_read_temp(struct fxls8971_instance *dev, int8_t *deg_c)
    Reads the temperature in degrees C (TEMP_OUT + 25).
  • int32_t fxls8971_to_mg(const struct fxls8971_instance *dev, int16_t raw)
    Converts a raw sample to milli-g for the configured range (1024 LSB/g at +/-2 g).

Note: boot mode

The FXLS8971CF latches its BT_MODE pin at power-up. With BT_MODE = VDD (as on the MachXO4 Companion board) it starts in motion detection mode and goes straight to WAKE at 0.78 Hz. fxls8971_init() handles this: it switches to Standby, sets the data rate and range (low-power mode only, as the datasheet advises for this mode) and makes the sensor Active again.

Example: read the accelerometer

#include "sys_platform.h"
#include "fxls8971.h"

static struct i2c_master_instance i2c0;
static struct fxls8971_instance   acc;

int accel_demo(uint32_t i2c_base, uint32_t pclk_hz)
{
    struct fxls8971_data d;
    int ret;

    if (i2c_master_init(&i2c0, i2c_base) != I2C_MASTER_OK) {
        return -1;                                  /* block not found */
    }
    i2c_master_set_speed(&i2c0, pclk_hz, 400000);  /* 400 kHz */

    ret = fxls8971_init(&acc, &i2c0, FXLS8971_ADDR_SA0_LOW,
                        FXLS8971_RANGE_2G, FXLS8971_ODR_100HZ);
    if (ret != FXLS8971_OK) {
        return ret;
    }
    while (1) {
        if (fxls8971_data_ready(&acc) == 1 && fxls8971_read_xyz(&acc, &d) == FXLS8971_OK) {
            int32_t x_mg = fxls8971_to_mg(&acc, d.x);
            int32_t y_mg = fxls8971_to_mg(&acc, d.y);
            int32_t z_mg = fxls8971_to_mg(&acc, d.z);
            /* use x_mg, y_mg, z_mg */
        }
    }
}
