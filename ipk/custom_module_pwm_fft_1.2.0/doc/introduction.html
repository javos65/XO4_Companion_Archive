PWM_FFT 1.2.0 – PWM audio spectrum analyser (APB)

Takes one PWM audio signal, recovers the 16 kHz audio samples, computes a 256-point FFT every 256 samples (16 ms) and reports the spectrum as 12 bands with a level of 0 to 7 each: one band for 50 to 500 Hz and 11 logarithmic bands from 500 Hz to 8 kHz. The levels are read over APB as two 32-bit words of 4-bit values. The block needs no DSP blocks: it uses one sequential shift-and-add multiplier.

Parameter

NameDefaultDescription
WIN_CLKS1500CORE_CLK cycles per audio sample (64..4095). Must be an exact multiple of the PWM carrier period, with CORE_CLK from the same clock source as the PWM, so the average duty cycle is measured without phase error. TTS_APB: carrier 750 cycles of 24 MHz, 2 carrier periods per 16 kHz sample = 1500.

Clock domains

All sampling and FFT logic runs on CORE_CLK; the APB registers run on PCLK. CTRL and SCALE are copied into the core by a toggle handshake after each write (allow a few CORE_CLK cycles between writes). Each new set of results is copied into the PCLK domain by a toggle handshake once per frame; the core keeps it stable for a whole frame.

Processing

  1. PWM high time over WIN_CLKS cycles minus WIN_CLKS/2, scaled: signed sample (about ±12000 full scale).
  2. Frame of 256 samples, frame mean removed, optional periodic Hann window, bit-reversed load.
  3. 256-point radix-2 FFT, in place, scaled by 1/2 per stage (62.5 Hz per bin at 16 kHz).
  4. Power re² + im² of bins 1..127 summed into 12 bands; L = 4 × log2(power).
  5. Level = 0 if L < FLOOR, otherwise min(7, 1 + (L − FLOOR) / STEP); peak hold falls one level every DECAY frames.

Processing a frame takes about 92,000 CORE_CLK cycles: about 3.8 ms at 24 MHz, well inside the 16 ms frame.

Bins per band: 7, 3, 3, 4, 4, 7, 8, 10, 14, 17, 22, 28. The band power is a sum over its bins; to correct for the band width subtract k × log2(bins) from RAW (k = 4: per-bin power, k = 2: half correction). With the Hann window a pure tone also shows in the next bin on each side at −6 dB.

Registers (PCLK domain)

OffsetNameAccessDescription
0x00IDR0x50464654 ("PFFT")
0x04CTRL / STATUSW / RWrite CTRL: [0] EN (reset 1), [1] WINDOW Hann (reset 1), [11:8] DECAY frames per level step (reset 2, 0 = follow every frame).
Read STATUS: [0] EN, [1] WINDOW, [11:8] DECAY, [12] READY new levels since the last LEVELS_LO read, [13] BUSY, [31:16] frame counter
0x08SCALERW[7:0] FLOOR (reset 36), [12:8] STEP (reset 8 = 2 × log2 = about 6 dB), both in quarter log2 steps
0x0CLEVELS_LORBands 1..8, 4 bits each: [3:0] band 1 ... [31:28] band 8. Reading clears READY and captures LEVELS_HI of the same frame.
0x10LEVELS_HIRBands 9..12, 4 bits each: [3:0] band 9 ... [15:12] band 12, [31:16] = 0
0x40 + 4·bRAW[b]R[7:0] L = 4 × log2(power) of band b+1, b = 0..11

Read LEVELS_LO first, then LEVELS_HI. With the reset scale, a full-scale TTS tone gives L of about 90 (level 7) and each level step is about 6 dB.

Driver functions (driver/pwm_fft.h)

The driver files are pwm_fft.h, pwm_fft.c and pwm_fft_regs.h. The driver uses reg_32b_read() / reg_32b_write() from the Propel BSP (reg_access.h). One struct pwm_fft_instance describes one block (instance_name, base_address). Constants: PWM_FFT_NUM_BANDS (12), PWM_FFT_LEVEL_MAX (7).

FunctionDescription
uint8_t pwm_fft_init(struct pwm_fft_instance *this_fft, uint32_t base_addr) Binds the instance to the base address of the block and checks the ID register. Returns PWM_FFT_OK (0), PWM_FFT_ERR_PARAM (1) for a null pointer, or PWM_FFT_ERR_ID (2) if the ID register does not read 0x50464654 (block not found at this address).
void pwm_fft_config(struct pwm_fft_instance *this_fft, uint8_t enable, uint8_t window, uint8_t decay) Writes CTRL: enable 1 runs the analyser, window 1 uses the Hann window, decay 0..15 is the number of frames per falling level step of the peak hold (0 = levels follow every frame). Reset values: enable 1, window 1, decay 2. Allow a few CORE_CLK cycles before the next CTRL or SCALE write.
void pwm_fft_set_scale(struct pwm_fft_instance *this_fft, uint8_t floor, uint8_t step) Writes SCALE for the hardware levels: floor (0..255) is the RAW value of level 1, step (0..31) the RAW units per further level, both in quarter log2 steps (4 units = 3 dB, step 8 = about 6 dB per level). Reset values: floor 36, step 8.
uint8_t pwm_fft_ready(struct pwm_fft_instance *this_fft) Returns 1 when a new set of levels was published since the last pwm_fft_read_levels() or pwm_fft_read_packed(), otherwise 0 (also 0 for a null pointer). A new set arrives every 16 ms.
void pwm_fft_read_levels(struct pwm_fft_instance *this_fft, uint8_t levels[PWM_FFT_NUM_BANDS]) Reads LEVELS_LO and then LEVELS_HI of the same frame and unpacks them into levels[0..11] (levels[0] = band 1, 50-500 Hz), each 0..7. Clears READY.
void pwm_fft_read_packed(struct pwm_fft_instance *this_fft, uint32_t *lo, uint32_t *hi) Reads the two packed level words: lo = bands 1..8, hi = bands 9..12, 4 bits per band. Either pointer may be NULL. Clears READY.
uint8_t pwm_fft_read_raw(struct pwm_fft_instance *this_fft, uint8_t band) Returns RAW of band band (0..11): L = 4 × log2(band power) of the last frame. Use it to tune FLOOR and STEP, or to compute levels in firmware (averaging, width correction). Returns 0 for a bad band or null pointer.

pwm_fft_regs.h holds the register offsets (PWM_FFT_REG_*, PWM_FFT_REG_RAW(b)), the bit definitions (PWM_FFT_CTRL_*, PWM_FFT_STATUS_READY, PWM_FFT_STATUS_BUSY, PWM_FFT_STATUS_FRAMES(v), PWM_FFT_SCALE_*) and PWM_FFT_ID_VALUE.

Example 1: read the hardware levels with the driver

#include "pwm_fft.h"

static struct pwm_fft_instance fft0;

/* fft_base: base address of the PWM_FFT instance (from sys_platform.h). Returns 0 when running. */
int spectrum_start(uint32_t fft_base)
{
    if (pwm_fft_init(&fft0, fft_base) != PWM_FFT_OK) {
        return -1;                          /* block not found at this address */
    }
    pwm_fft_config(&fft0, 1u, 1u, 2u);      /* enabled, Hann window, fall one level every 2 frames */
    pwm_fft_set_scale(&fft0, 36u, 8u);      /* level 1 at L = 36, about 6 dB per level */
    return 0;
}

/* Call from the main loop: returns 1 and fills levels[0..11] (0..7) when a new frame (16 ms) is ready. */
int spectrum_poll(uint8_t levels[PWM_FFT_NUM_BANDS])
{
    if (!pwm_fft_ready(&fft0)) {
        return 0;
    }
    pwm_fft_read_levels(&fft0, levels);    /* levels[0] = 50-500 Hz ... levels[11] = 6.2-8 kHz */
    return 1;
}

Example 2: RAW values with direct register access

The TTS FFT demo computes its own levels from RAW (4-frame average, band width correction). It detects a new frame from the frame counter in STATUS and reads the 12 RAW registers directly:

#include <stdint.h>
#include "pwm_fft_regs.h"

#define REG32(a)  (*(volatile uint32_t *)(uintptr_t)(a))

static uint32_t last_frame;

/* Returns 1 and fills raw[0..11] (L = 4 * log2(power), 4 units = 3 dB) when a new frame was published. */
int fft_read_raw(uint32_t fft_base, uint8_t raw[12])
{
    uint32_t f = PWM_FFT_STATUS_FRAMES(REG32(fft_base + PWM_FFT_REG_STATUS));
    uint32_t b;

    if (f == last_frame) {
        return 0;
    }
    last_frame = f;
    for (b = 0; b < 12u; b++) {
        raw[b] = (uint8_t)REG32(fft_base + PWM_FFT_REG_RAW(b));
    }
    return 1;
}

Width correction example: subtract 2 × log2(bins / 3) per band ({2, 0, 0, 1, 1, 2, 3, 3, 4, 5, 6, 6}) from RAW so the wide high bands do not dominate.

Devices Supported

LFMXO4, LFMXO5, LFCPNX, LFD2NX, LIFCL, LAV-AT. The three 256 x 16-bit sample and FFT buffers are inferred as block RAM.
