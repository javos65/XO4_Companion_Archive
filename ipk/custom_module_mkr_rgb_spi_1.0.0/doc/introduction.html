MKR_RGB_SPI 1.0.0 – APA102 LED chain controller (APB)

custom:module:mkr_rgb_spi:1.0.0. Drives a daisy chain of APA102 / APA102-2020 RGB LEDs, for example the Arduino MKR RGB Shield (84 LEDs, 7 rows × 12 columns). Software fills a pixel buffer (one block RAM), then writes CTRL.START. The block sends a start frame (32 × 0), the LED frames and an end frame (64 × 1) on LED_SDI / LED_CKI.

Register map

OffsetNameAccessDescription
0x000IDR0x52474231 ("RGB1"). Used by the driver to detect the block
0x004CTRLRWbit0 START (W): 1 sends one frame; ignored while busy; reads 0.
bit1 READY (R): 1 = idle, the buffer may be written and read
0x008NLEDSRNUM_LEDS
0x00C + 4·iPIX[i]RWLED frame of LED i (i = 0 is the first LED in the chain), sent MSB first:
[31:29] 111 | [28:24] brightness 0..31 | [23:16] blue | [15:8] green | [7:0] red
0x00C..0x158 for 84 LEDs

While READY = 0 the RAM read port belongs to the serial engine: PIX writes are ignored and PIX reads return undefined data. Always wait for READY before writing the buffer. A frame of 84 LEDs takes 2784 CKI clocks (278.4 µs at 10 MHz).

Driver

Files: mkr_rgb_spi.h, mkr_rgb_spi.c, mkr_rgb_spi_regs.h. The driver keeps a frame buffer in RAM (fb[7][12] RGB values plus one global brightness). Drawing functions only change that buffer; mkr_rgb_show() copies it to the PIX registers and starts the transfer.

Coordinates: x = column 0..11 (left to right), y = row 0..6 (top to bottom). On the MKR RGB Shield the chain runs row by row, each row left to right, so chain index = y * 12 + x.

uint8_t mkr_rgb_init(struct mkr_rgb_instance *this_rgb, uint32_t base_addr)

Binds the instance to the block at base_addr, checks ID = 0x52474231 and NLEDS ≥ 84, clears the frame buffer, sets brightness 8 and no orientation flip. The LEDs are not updated until mkr_rgb_show(). Returns MKR_RGB_OK, MKR_RGB_ERR_PARAM (null pointer), MKR_RGB_ERR_ID (no block at that address) or MKR_RGB_ERR_SIZE (chain shorter than the matrix).

uint8_t mkr_rgb_is_ready(struct mkr_rgb_instance *this_rgb)

Reads CTRL.READY. Returns 1 when no frame is being sent, 0 while busy (or for a null pointer).

uint8_t mkr_rgb_wait_ready(struct mkr_rgb_instance *this_rgb)

Polls READY, at most MKR_RGB_TIMEOUT_POLLS (100000) times. Returns MKR_RGB_OK or MKR_RGB_ERR_TIMEOUT; never hangs.

void mkr_rgb_set_brightness(struct mkr_rgb_instance *this_rgb, uint8_t brightness)

APA102 global brightness for all pixels, 0..31 (values above 31 are clipped). It scales the LED current, so a low value also limits the supply current. Takes effect at the next mkr_rgb_show().

void mkr_rgb_set_orientation(struct mkr_rgb_instance *this_rgb, uint8_t flags)

MKR_RGB_FLIP_X mirrors left/right, MKR_RGB_FLIP_Y mirrors top/bottom; both together rotate the image by 180°. Use it when the shield is mounted turned; the application keeps using the same coordinates.

void mkr_rgb_clear(struct mkr_rgb_instance *this_rgb)

Sets every pixel of the frame buffer to black.

void mkr_rgb_fill(struct mkr_rgb_instance *this_rgb, uint8_t r, uint8_t g, uint8_t b)

Sets every pixel of the frame buffer to one colour.

void mkr_rgb_set_pixel(struct mkr_rgb_instance *this_rgb, uint8_t x, uint8_t y, uint8_t r, uint8_t g, uint8_t b)

Sets one pixel of the frame buffer. Coordinates outside 0..11 / 0..6 are ignored.

void mkr_rgb_write_image(struct mkr_rgb_instance *this_rgb, const mkr_rgb_rgb_t img[7][12])

Copies a whole 7 × 12 image (img[y][x]) into the frame buffer.

uint8_t mkr_rgb_show(struct mkr_rgb_instance *this_rgb)

Waits for READY, writes the 84 PIX registers (brightness and orientation applied) and writes CTRL.START. Returns as soon as the transfer has started (it does not wait the 278 µs). Returns MKR_RGB_OK, MKR_RGB_ERR_PARAM or MKR_RGB_ERR_TIMEOUT (nothing is sent then).

mkr_rgb_rgb_t mkr_rgb_hue(uint16_t hue)

Colour wheel helper: hue 0..1535 (6 × 256 steps: red, yellow, green, cyan, blue, magenta, back to red), full saturation and value. Values above 1535 wrap.

Example code

With Propel's generated sys_platform.h (instance mkr_rgb0_inst):

#include "sys_platform.h"
#include "mkr_rgb_spi.h"

static struct mkr_rgb_instance matrix;

/* a 7 x 12 image: red top row, green bottom row, black elsewhere */
static const mkr_rgb_rgb_t image[MKR_RGB_HEIGHT][MKR_RGB_WIDTH] = {
    [0]                 = { [0 ... MKR_RGB_WIDTH - 1] = {255, 0, 0} },
    [MKR_RGB_HEIGHT - 1] = { [0 ... MKR_RGB_WIDTH - 1] = {0, 255, 0} },
};

int rgb_demo(void)
{
    uint8_t x, y;

    matrix.instance_name = MKR_RGB0_INST_NAME;
    if (mkr_rgb_init(&matrix, MKR_RGB0_INST_BASE_ADDR) != MKR_RGB_OK) {
        return -1;                              /* block not found */
    }
    mkr_rgb_set_brightness(&matrix, 4);         /* 4/31: low current */
    /* mkr_rgb_set_orientation(&matrix, MKR_RGB_FLIP_X | MKR_RGB_FLIP_Y);   if mounted upside down */

    /* 1. a whole image */
    mkr_rgb_write_image(&matrix, image);
    mkr_rgb_show(&matrix);

    /* 2. single pixels: a rainbow diagonal */
    mkr_rgb_clear(&matrix);
    for (x = 0; x < MKR_RGB_WIDTH; x++) {
        mkr_rgb_rgb_t c = mkr_rgb_hue((uint16_t)(x * 128u));
        y = (uint8_t)(x * MKR_RGB_HEIGHT / MKR_RGB_WIDTH);
        mkr_rgb_set_pixel(&matrix, x, y, c.r, c.g, c.b);
    }
    return (mkr_rgb_show(&matrix) == MKR_RGB_OK) ? 0 : -1;
}

Direct register access without the driver (one LED, full red at brightness 4):

#include "reg_access.h"
#include "mkr_rgb_spi_regs.h"

uint32_t base = MKR_RGB0_INST_BASE_ADDR, ctrl = 0, i;

do { reg_32b_read(base + MKR_RGB_SPI_REG_CTRL, &ctrl); } while (!(ctrl & MKR_RGB_SPI_CTRL_READY));
for (i = 0; i < 84; i++) {
    reg_32b_write(base + MKR_RGB_SPI_REG_PIX(i), MKR_RGB_APA102_WORD(4, i == 0 ? 255 : 0, 0, 0));
}
reg_32b_write(base + MKR_RGB_SPI_REG_CTRL, MKR_RGB_SPI_CTRL_START);
