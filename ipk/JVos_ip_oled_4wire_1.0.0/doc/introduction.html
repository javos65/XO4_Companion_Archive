oled_4wire: APB to 4-wire SPI (SSD1306 OLED)

Version 1.0.0. APB slave peripheral for Lattice Propel that sends command and data bytes to a serial SSD1306 OLED controller (for example the Digilent Pmod OLED, 128 x 32) over a write-only 4-wire SPI interface (CS#, D/C#, SCLK, SDIN). It also drives the display reset (RES#) and the two active-low supply switches of the Pmod OLED (VBATC, VDDC) under software control. The package contains the RTL, the register map and a BSP driver set (section 5).

1. Features

  • Single clock domain (PCLK), zero wait-state APB slave, 8-bit address, 32-bit data.
  • 16 entry by 9-bit FIFO (D/C# plus byte), flags FULL / EMPTY / IDLE, sticky overflow flag.
  • SPI mode 0, MSB first. SCLK = PCLK / (2 * (CLKDIV + 1)); CLKDIV is a register (reset value 1: 24 MHz gives 6 MHz).
  • RES#, VBATC# and VDDC# are software controlled; after reset the display is unpowered and held in reset.
  • BSP driver set with SSD1306 routines, power and reset sequence, selectable display orientation, Lattice logo (normal or upside down) and a 6 x 8 fixed font. The call names of the earlier SPI_4Wire driver are kept.

4. Pmod OLED start-up sequence

  1. VDDC_N = 0 (logic supply on), RES_N = 0, wait 5 ms. Then RES_N = 1, wait 5 ms.
  2. Send the initialisation commands with the display still off (oled_init).
  3. Send the orientation commands (segment re-map and COM scan direction), see section 5.4.
  4. Wait until the FIFO is empty and the shifter is idle.
  5. VBATC_N = 0 (display supply on), wait 100 ms.
  6. Send display on (oled_on).

oled_start_ssd1306(orientation) performs all of these steps. VDDC and VBATC drive P-channel switches with pull-up resistors on the Pmod OLED: a high or undriven pin leaves the supply off, and driving the pin low turns it on.

5. BSP driver (driver/ssd1306.c, ssd1306.h, font_1bpp.c, font_1bpp.h)

5.1 Use and conventions

  • The driver is enabled by #define SSD1306_DRIVER in ssd1306.h. Only one OLED driver may be defined in a firmware project, because every driver defines the symbol SPI_BASE.
  • The peripheral base address is passed once with base_ssd1306(). Propel generates it as OLED_SPI0_INST_BASE_ADDR in sys_platform.h for an instance named oled_spi0_inst.
  • Dependencies: delay(ms) from utils.h (the delays assume the system clock is configured correctly) and printf() from stdio.h (timeout messages).
  • Functions that return a status return 1 for success and 0 for failure or timeout.
  • The driver is not re-entrant: all functions share the window array oled_graph and the base address.
  • The display is page based. One data byte covers 8 vertical pixels of one column, with bit 0 at the top of the page. The 128 x 32 panel has 4 pages of 128 columns. The driver uses horizontal addressing: the column pointer advances after every data byte and the page advances at the end of the window.

5.2 Register access

FunctionDescription
void base_ssd1306(uint32_t address) Stores the peripheral base address and reads CONTROL once to initialise the internal copy of the register. Call first.
uint32_t getbase_ssd1306(void)Returns the stored base address.
void writeSPIMemory_ssd1306(uint8_t offset, uint32_t data) Writes a 32-bit value to the register at the byte offset (0x00 ID, 0x04 STATUS, 0x08 CONTROL, 0x0C DATA). For diagnostics.
uint32_t readSPIMemory_ssd1306(uint8_t offset) Reads the register at the byte offset, for example the ID (expect 0x4F4C4401) or STATUS.

5.3 Byte transfer

FunctionDescription
uint8_t command_ssd1306(uint8_t command) Sends one command byte (D/C# = 0). Waits for FIFO space first, at most about 8 ms. Returns 1, or 0 on timeout.
uint8_t data_ssd1306(uint8_t data) Sends one data byte (D/C# = 1), in the same way.
void commandlist_ssd1306(const uint8_t *list, uint8_t size) Sends size command bytes from an array, one after the other. Individual failures are ignored.

5.4 Power, reset and orientation

FunctionDescription
void oled_reset_ssd1306(void) Switches the logic supply on (VDDC low), keeps the display in reset for 5 ms, releases reset and waits 5 ms.
void oled_vbat_ssd1306(uint8_t on) Switches the display supply (VBATC) on (1) or off (0) and waits 100 ms.
void oled_clkdiv_ssd1306(uint8_t clkdiv) Sets the SPI clock divider: SCLK = PCLK / (2 * (clkdiv + 1)).
uint8_t oled_flush_ssd1306(void) Waits until the FIFO is empty and the last byte has been shifted out (STATUS IDLE). Returns 1, or 0 on timeout (about 130 ms).
void oled_orientation_ssd1306(uint8_t orientation) Selects the picture orientation, see below. Call before drawing. If it is called later, redraw the whole screen, because the column mapping only applies to data written afterwards.
void oled_start_ssd1306(uint8_t orientation) Complete start-up: reset, oled_init, orientation, flush, VBAT on (100 ms), display on, flush.
void oled_stop_ssd1306(void) Display off, flush, VBAT off, then VDD off with the display held in reset.
Orientation constantCommandsEffect
OLED_ORIENT_NORMAL (0)A1 (segment re-map) and C8 (COM scan reversed) The orientation used so far. The picture is upright on the Companion board with the Pmod OLED plugged in.

5.5 Graphics

FunctionDescription
void oled_clear_ssd1306(uint8_t pattern) Fills the whole screen (columns 0 to 127, pages 0 to 3, 512 bytes) with pattern. Pattern 0x00 gives a black screen.
void oled_setblock_ssd1306(uint8_t column, uint8_t page, uint8_t width, uint8_t height) Defines a write window of width columns by height pages and resets the start line. Data bytes sent afterwards fill the window and wrap inside it.
void oled_clearblock_ssd1306(uint8_t column, uint8_t page, uint8_t width, uint8_t height, uint8_t pattern) Defines the window as above and fills it with pattern (width * height bytes).
void oled_lattice_ssd1306(uint8_t column, uint8_t page, uint8_t type, uint8_t orientation) Draws the Lattice logo (120 x 24 pixels, 3 pages, 360 bytes) with its top-left corner at the given column and page. type: 1 = normal pixels, any other value = inverted pixels. orientation: OLED_LOGO_NORMAL (0) draws the bitmap as stored in lattice_logo[], OLED_LOGO_UPSIDE_DOWN (1) draws it rotated by 180 degrees in the same window (column order, page order and the bit order inside every byte are reversed). Nothing is drawn if the logo does not fit on the display at that position.

The logo orientation argument only changes the bitmap data. It is independent of the display orientation of section 5.4: with the display upside down, pass OLED_LOGO_UPSIDE_DOWN to see the logo upright.

FunctionDescription

5.8 Example

#include "sys_platform.h"
#include "ssd1306.h"
#include "font_1bpp.h"

base_ssd1306(OLED_SPI0_INST_BASE_ADDR);          /* peripheral base address            */
oled_start_ssd1306(OLED_ORIENT_UPSIDE_DOWN);     /* power up, init, orientation, on    */
oled_clear_ssd1306(0x00);                        /* black screen                       */
oled_lattice_ssd1306(4, 0, 1, OLED_LOGO_NORMAL); /* logo at column 4, page 0           */
draw_text_ssd1306(" XO4 Rules!", fixed8x6, 6, 3, TEXT_NORMAL); /* text on page 3       */
