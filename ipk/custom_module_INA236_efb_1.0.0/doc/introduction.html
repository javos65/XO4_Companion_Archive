INA236_efb 1.0.0

1. Purpose

APB-mapped access block for up to four TI INA236A current and voltage monitors on the MachXO4 EFB primary I2C controller (I2C1). The block is placed between the APB interconnect and the lscc_efb IP (APB interface, 32-bit data, 10-bit address) and passes every APB signal through 1:1. It has no registers and no clock, so it adds no clock domain. It gives the I2C controller its own address window and comes with a BSP driver that implements the EFB I2C master and the INA236A layer (identification, calibration, measurement, integer conversion).

4. Required lscc_efb settings

  • User interface APB, 32-bit data width, 10-bit address width (as in the IS25LP064A_efb precedent).
  • Primary I2C enabled, access type User; secondary I2C, SPI, timer/counter, PLL access and UFM disabled.
  • User interface clock frequency equal to the APB clock of the system (12 MHz in the reference design) and I2C bus performance 100 kHz; the clock prescale value is then 30 (0x1E). The driver also programs the prescale at start-up.
  • The ports i2c1_scl and i2c1_sda must be connected to the bidirectional top-level ports. They are the fixed pins of the hardened controller (A9 and C9 on the MachXO4 Companion Board). Use the external pull-ups of the board (4.7 kohm to 3.3 V) and no internal pull-ups.

7. BSP driver (INA236_efb.h)

  • Set-up: ina236_efb_init, ina236_i2c_init (prescale from the APB clock and the I2C rate), ina236_i2c_reset, ina236_i2c_recover
  • Raw I2C: ina236_i2c_write, ina236_i2c_write_read (repeated START)
  • INA236A registers: ina236_read_reg, ina236_write_reg, ina236_probe
  • Calibration: ina236_calc_shunt_cal, ina236_channel_default, ina236_configure
  • Measurement: ina236_read_sample (bus mV, current mA, power mW, shunt uV, raw values), ina236_strerror

All functions are blocking, poll the controller with a bounded loop, use no interrupts and return 0 or a negative INA236_ERR_* code (timeout, NACK, arbitration lost, argument, ID, calibration). The code is integer only (RV32I, no multiplier, no floating point).

Usage example

#include "INA236_efb.h"

#define INA_BASE   0x8800u
#define APB_HZ     12000000u

static struct ina236_efb_instance ina;
static struct ina236_channel ch[4];
static const uint8_t addrs[4] = { 0x40, 0x41, 0x42, 0x43 };

void ina_start(void)
{
    ina236_efb_init(&ina, INA_BASE);
    ina236_i2c_init(&ina, APB_HZ, 100000u);            /* prescale 30 */
    for (int i = 0; i < 4; i++) {
        ina236_channel_default(&ch[i], addrs[i], 10000u, 1000u);  /* 10 mohm, 1 mA LSB */
        if (ina236_probe(&ina, addrs[i]) == INA236_OK)
            ina236_configure(&ina, &ch[i]);
    }
}

int ina_poll(int i, struct ina236_sample *s)
{
    return ina236_read_sample(&ina, &ch[i], s);        /* s->bus_mv, s->current_ma, s->power_mw */
}

8. Known limits

  • The EFB I2C controller cannot generate free-running SCL pulses, so a stuck SDA held by a target cannot be released by the driver (ina236_i2c_recover only issues STOP and resets the core).
  • The driver uses CKSDIS = 0 (controller operation); the example in the EFB guide uses CKSDIS = 1. The byte-level handshake (TRRDY, TIP, RARC) is to be confirmed on hardware.
  • Power conversion is exact for a current LSB of 1000 uA; larger LSB values can overflow 32 bits.
  • The ALERT output of the devices is not used.
